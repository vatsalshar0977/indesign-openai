# Arena Link — the agent's own InDesign plugin

A small UXP panel written for this workspace. It has **nothing to do with OpenAI**: no API
key, no model dropdown, no account. It connects InDesign to the Arena bridge, and from there
to the agent.

- **Ask** — type an instruction, press *Send*. The request goes to the bridge, the agent
  answers, the text lands in the panel. *Insert* places it in the document.
- **Agent drives InDesign** — with the switch on (default), the agent can read and edit the
  open document directly: selection, frames, find/replace, alt text, export.

The old `OpenAI-4-InDesign` panel is not needed for any of this. Its source is still in
`src/` for reference; Arena Link is the plugin to install.

## Install

Build (bridge address baked in) or install from source:

```bash
BRIDGE_URL=https://8787-xxxxx.e2b.app npm run build:arena   # -> Plugin/ArenaLink.ccx
```

Then on Windows, in the UXP world, the same three routes as any UXP plugin apply —
see **[INSTALL-WINDOWS.md](INSTALL-WINDOWS.md)** (player debug mode / UPIA / folder copy),
using:

- package: `Plugin/ArenaLink.ccx`
- source folder: `arena-link/`
- target folder for the copy route: `%APPDATA%\Adobe\UXP\Plugins\External\arenaIndesignLink`

The manifest already allows `https://*.e2b.app`, `http://localhost:8787` and
`http://127.0.0.1:8787`, so the sandbox host can change without rebuilding and a local bridge
works out of the box.

## Using the panel

| element | what it does |
| --- | --- |
| URL field + **Connect** | bridge address, stored in the plugin (empty = nothing happens) |
| **Let the agent drive InDesign** | on by default; long-polls the bridge for commands |
| **Send** | sends the instruction (plus the context field) to the agent |
| arrow button | imports the selected text into the context field |
| **Insert** | writes the answer into the current selection |
| copy button | copies the answer to the clipboard |

Status line: *Connected · host* (green), *Waiting for the agent …*, or the error.

## Commands the agent can run

Everything runs through `app.doScript()` as one undo step. Unknown ops return an error; there
is no `eval` and no way to run arbitrary code.

| command | args | returns |
| --- | --- | --- |
| `ping` | – | app name/version, `bridge: "arena"` |
| `app.info` | – | open documents, active document, selection kinds |
| `doc.info` | – | name, path, pages, spreads, size, units, story/link counts |
| `doc.list` | – | all open documents |
| `page.info` | – | active page name, index, item counts |
| `selection.get` | `limit`, `maxChars`, separators | text/table of the selection, alt text |
| `selection.set` | `text`, separators | replaces the selection (tables cell by cell) |
| `frames.list` | `limit`, `maxChars`, `scope: "page"` | text frames of the active spread or page |
| `frame.set` | `index` \| `name` \| `label`, `text` | overwrites one frame |
| `text.append` | `text`, `storyIndex` | appends to the end of a story |
| `text.find` | `find`, `grep`, `limit` | matches with previews |
| `text.replace` | `find`, `replace`, `grep` | number of replacements |
| `styles.list` | – | paragraph and character style names |
| `links.list` | `limit` | linked images and status |
| `altText.get` / `altText.set` | `text` | read/write alt text of the selection |
| `doc.save` | – | saves the active document |
| `doc.export` | `format: pdf \| idml \| jpeg \| png \| eps` | export to the plugin temp folder |
| `image.get` | – | selected image as base64 JPEG, so the agent can see it |

## Layout

```
arena-link/
  manifest.json        id: arenaIndesignLink, host InDesign 18.5+
  index.html           panel markup (Spectrum Web Components)
  main.js              UXP entrypoint
  main.css
  lib/config.js        bridge URL + agent switch (localStorage, build-time default)
  panel/panel.js       UI wiring, agent link long poll, ask/answer flow
  panel/ops.js         the whitelisted InDesign operations
  assets/icons/        generated by scripts/make-icons.mjs
```

## Tests

```bash
npm run bridge &
npm run test:arena     # mocked UXP + InDesign, real panel code, live bridge
```

`test/arena-smoke.mjs` checks setup, the ask→answer round trip, and seven commands including
that an unknown op is rejected.
