Quick reference

CommandArgsDoes
ping–App name + version, proves the link works
app.info–Open documents, active document name, selection kind
doc.info–Active document: name, path, pages, size, units
doc.list–All open documents
selection.get–Text of the current selection (frames or tables)
selection.set{ text }Replaces the selection with new text
frames.list{ limit }Text frames of the active spread with contents
frame.set{ index|name, text }Overwrites one text frame
text.append{ text }Appends text to the first story of the active doc
doc.export{ format: "pdf"|"idml"|"jpeg"|"png" }Exports to the plugin temp folder, returns the file path

Model requests (Send button in the panel) arrive as jobs above; the agent answers them and the text lands back in the panel — no OpenAI key involved.
